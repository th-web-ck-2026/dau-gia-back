6. auth

🔴 Có lỗ hổng bảo mật

Authentication - JWT + Google + Email

✅ controller ✅ 3 services ✅ 6 DTO ✅ jwt strategy ✅ 2 entity ✅ 2 model ✅ repositories

Issues nghiêm trọng:

  • [P0] Controller có @Public() ở scope toàn bộ → change-password, logout-all crash do request.user undefined
  • [P0] resetPassword update password vào bảng user thay vì auth_provider → reset xong không login được
